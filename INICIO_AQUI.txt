================================================================================
                        📋 PRIMEIROS PASSOS
================================================================================

1️⃣ TESTAR O SISTEMA
   ────────────────────────────────────────────────────────────────────────
   Clique duas vezes em:
   
   ► executar_testes.bat
   
   Isso vai verificar se tudo está funcionando corretamente.


2️⃣ CRIAR PLANILHA (se não existir)
   ────────────────────────────────────────────────────────────────────────
   Clique duas vezes em:
   
   ► criar_planilha.bat
   
   Isso vai criar a planilha RELATORIO_INVENTARIO.xlsx com a estrutura correta.


3️⃣ CONFIGURAR PARA REDE
   ────────────────────────────────────────────────────────────────────────
   ⚠️ IMPORTANTE: Feche o Excel antes!
   
   Clique duas vezes em:
   
   ► configurar_rede.bat
   
   Isso vai preparar a planilha para uso em rede compartilhada.


4️⃣ LER A DOCUMENTAÇÃO
   ────────────────────────────────────────────────────────────────────────
   Abra um destes arquivos:
   
   ► GUIA_RAPIDO.md          (Guia prático passo a passo)
   ► README.md               (Documentação completa)
   ► RESUMO_AJUSTES.txt      (Resumo das mudanças)
